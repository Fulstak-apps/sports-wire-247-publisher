# Crash Out Sports 24/7 publisher

This repository monitors sports news, selects and verifies one publishable development, creates an original Crash Out Sports carousel and Story, and publishes to Instagram and Threads through Meta's APIs. GitHub Actions checks every 20 minutes, but publishes only when a qualified non-duplicate story exists.

Required repository secrets:

- `OPENAI_API_KEY`: used for editorial selection, web verification, copy and original artwork.
- `INSTAGRAM_ACCESS_TOKEN`: the long-lived token generated by the Crash Out Sports Meta app.
- `INSTAGRAM_USER_ID`: the numeric Instagram professional-account ID.
- `THREADS_ACCESS_TOKEN`: the token for the connected Crash Out Sports Threads profile.
- `THREADS_USER_ID`: the numeric Threads profile ID.

The repository must be public so Meta can download images from `raw.githubusercontent.com`. Tokens remain encrypted GitHub Actions secrets and are never committed. The default source monitor checks independent WNBA, NBA, NFL, MLB, NHL, NCAA and unusual-sports news searches; `SPORTS_RSS_URLS` can optionally replace them with a comma-separated approved feed list.

Add each carousel's PNG files under `media/`, then add a matching JSON file under `queue/` with `status` set to `ready`. The workflow publishes every ready item and changes its status to `published`.

Instagram's API cannot attach a song from Instagram's licensed music library to a feed carousel. That music selection remains a manual Instagram-app step.

Editorial metadata must identify the league, story type, confirmation status and at least
two credible sources. Official leagues, teams, schools, athletes, agents and transaction
wires are preferred. Reports, negotiations, rumors and allegations must be labeled. Trade
and contract details must not be stated as final until their status is verified.

Every ready item must use a rights-cleared, event-relevant visual. Source photos may be
used as factual references for materially original editorial artwork, but scraped broadcast
frames, watermarked photography and unlicensed highlight footage are rejected.

The brand lockup is always `CRASH OUT SPORTS`. The system covers WNBA, NBA, NFL, MLB,
NHL and NCAA, with regular women's-sports coverage and a limited verified lane for amateur,
international and unusual sports.

Use `publish_after` for precise queue timing. `MAX_FEED_POSTS_PER_RUN` defaults to one to
prevent a newly loaded batch from flooding the account. A check does not guarantee a post;
the newsroom fails closed when sourcing, rights or factual verification is insufficient.
